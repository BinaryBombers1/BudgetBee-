**Golden rules for the defense:**
1. Never bluff — use the honest-weakness table in 04-K; every gap has a named fix.
2. Anchor answers in *real numbers* (602 tx, 15-min JWT, 500/15 rate limits, 23–135 ms prod pages, Groq→rules fallback).
3. When unsure, say the trade-off you'd make and why — judges reward judgment over memorization.
